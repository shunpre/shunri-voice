# 瞬理 音声選定ルール

## 最初の評価軸

5候補は、派手さより次を優先して選びます。

1. 3秒聞いて不自然さが少ない
2. 30〜45秒聞いて疲れにくい
3. 知的だが広告ナレーター臭が強すぎない
4. 瞬理の見た目・立場（瞬LP AI広報）と一致する
5. あるある・解説・少し切ない台本のどれにも広げやすい
6. 固有名詞を除き、日本語の読みが安定している

## 推奨テスト

同じ台本で voice-a 〜 voice-e を生成し、まず声だけで比較します。

採用候補が2つまで絞れたら、次の3種類の台本で再比較します。

- 普通の解説
- あるある / 少しコミカル
- 静かで切ないトーン

3種類すべてで違和感が少ない声を「瞬理の基準声」にします。

## 固有名詞

読み間違いがある語は、音声生成用台本だけ読み仮名へ置換します。

- 瞬LP → しゅんエルピー
- CVR → シーブイアール

表示字幕は元の表記を維持します。

## 固定後

採用した音声を references/shunri.wav に置き、以後は --reference を付けて生成します。

参照音声はノイズ・BGM・別話者を含まない、きれいな音声を使います。30秒程度の良質な素材が集まった段階で、複数参照または Speaker Inversion への移行を検討します。
